# Projeto de Testes Automatizados com Selenium e Python

Este projeto é uma suíte de testes automatizados utilizando Python, Selenium WebDriver no padrão Page Object Model (POM), criado em acompanhamento às aulas de Testes de Sistemas da Especialização em Testes Ágeis.

## Estrutura do projeto

- `pages/`
    Contém os Page Objects, que abstraem a lógica de interação com as páginas da aplicação.

- `tests/` 
  Contém os casos de teste que utilizam os Page Objects para validar funcionalidades da aplicação.

## Pré-requisitos

- Python 3.11 ou superior  
- ChromeDriver (ou outro driver correspondente ao navegador que você usar)  
- Dependências Python (selenium, pytest, requests, webdriver-manager)


## Estrutura dos testes
Cada teste utiliza os Page Objects da pasta pages para realizar ações e verificações, garantindo assim um código organizado e reutilizável.
